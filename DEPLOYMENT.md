# Deployment Guide: Render (Backend) & Vercel (Frontend)

This project is configured for a decoupled full-stack deployment:
- **Render**: Hosts the FastAPI backend, LangChain/LangGraph agent, and connects to PostgreSQL.
- **Vercel**: Hosts the responsive vanilla HTML/CSS/JS frontend located in `frontent/`.

---

## 1. Backend Deployment on Render

### Overview
Render deploys directly from your GitHub repository using the Blueprint in `render.yaml`.

- **Repository**: `https://github.com/safvenn/expense-Agent.git`
- **Build Command**: `pip install uv && uv sync --frozen`
- **Start Command**: `uv run uvicorn app.main:app --host 0.0.0.0 --port $PORT`
- **Health Check Path**: `/Health`

### Required Environment Variables in Render
Under **Dashboard > Your Web Service > Environment**:

| Variable | Description | Example / Default |
| --- | --- | --- |
| `DATABASE_URL` | PostgreSQL connection string (asyncpg/psycopg compatible) | `postgresql://user:pass@host:5432/dbname` (e.g. Neon, Supabase, or Render Postgres) |
| `OPENAI_API_KEY` | API Key for model provider | `sk-...` |
| `OPENAI_BASE_URL` | (Optional) Hosted API endpoint if using custom provider | `https://api.openai.com/v1` or `https://api.groq.com/openai/v1` |
| `OPENAI_MODEL` | (Optional) Model name to use | `gpt-4o-mini`, `llama-3.3-70b-versatile`, etc. (defaults to `auto`) |
| `SECRET_KEY` | JWT signing secret | Automatically generated by Render via `render.yaml` |
| `ALGORITHM` | JWT signing algorithm | `HS256` |

### Steps to Deploy on Render:
1. Log in to [dashboard.render.com](https://dashboard.render.com).
2. Click **New +** > **Blueprint**.
3. Select your connected GitHub repository `safvenn/expense-Agent`.
4. Render will detect `render.yaml` and configure the `expense-assistant-api` service.
5. Provide the values for `DATABASE_URL` and `OPENAI_API_KEY`.
6. Click **Apply**.
7. Once deployment succeeds, note down your live Render service URL (e.g., `https://expense-assistant-api.onrender.com`).

## 2. Frontend Deployment on Vercel

### Overview
Vercel hosts the static frontend files in `frontent/` as configured in `vercel.json`.

- **Framework Preset**: Other / None
- **Root Directory**: `.` (or Output Directory set to `frontent`)
- **Build Command**: None (pure static assets)
- **Output Directory**: `frontent`

### Steps to Deploy on Vercel:

#### Option A: Via Vercel Web Dashboard (Recommended)
1. Go to [vercel.com/new](https://vercel.com/new).
2. Connect your GitHub account and import the repository `safvenn/expense-Agent`.
3. Vercel automatically reads `vercel.json` and sets `Output Directory` to `frontent`.
4. Click **Deploy**.
5. Once deployed, open your Vercel URL (e.g. `https://expense-agent-xyz.vercel.app`).
6. If the backend is running at a custom Render URL, you can enter it under **API connection** on the page or ensure it matches `https://expense-assistant-api.onrender.com`.

#### Option B: Via Vercel CLI
If you have Vercel CLI installed and authenticated:
```powershell
vercel login
vercel --prod
```

## 3. Verifying the Deployment
1. Verify the Render backend is healthy:
   ```bash
   curl https://<your-render-url>.onrender.com/Health
   # Returns: {"Msg":"running"}
   ```
2. Open the Vercel frontend URL in mobile or desktop browser.
3. Sign up with a new account or log in.
4. Send an expense message (e.g. *"Spent ₹250 on Biriyani for lunch"*).
5. Approve the action in the responsive tool approval card.
6. Open the **Expenses** tab to verify the transaction was persisted to PostgreSQL.
